# ✍ Inkpad

A fast, offline-first Markdown notebook that runs entirely in your browser.
No accounts, no backend, no dependencies — your notes stay in `localStorage`.

## Features

- Live split-view editor with a hand-written Markdown renderer
- Headings, emphasis, code fences, tables, task lists, blockquotes, links, images, `==highlights==`
- `#tags` are detected automatically and become filters in the sidebar
- Full-text search, pinned notes, relative timestamps
- Light & dark theme (follows your system preference)
- Export / import all notes as JSON
- Word count and reading time

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + N` | New note |
| `Ctrl + K` | Focus search |
| `Ctrl + P` | Cycle split / edit / preview |
| `Tab` | Indent in editor |
